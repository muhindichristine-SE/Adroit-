How It Works

Projects & Document Control

Create a project for each site inspection. Fill in Client, Contractor, Engineer, Drawn By, Checked By and Reviewed By — all of these print on the PDF cover page.

Tap Edit in any project to update these details.

Status Quick-Tap

Tap the coloured status badge (Open / In Progress / Closed) directly on any issue card to cycle through statuses without opening the edit form.

Drag to Reorder

Hold and drag the handle (⋮⋮) on any issue card to reorder. Tap Float Critical to automatically move all Critical issues to the top of the list.

Bulk Actions

Tap Select to enter bulk mode. Tap issue cards to select them, then use the action bar to mark as closed, in-progress, or delete multiple at once.

Export PDF & Word

Tap Export PDF or Export Word to generate a full inspection report with cover page, document control block, issue list and embedded photos. Works fully offline.

Backup & Restore

Your data is stored only on this device. Use Backup regularly to download a JSON file. Tap RESTORE to reload your data if you ever clear your browser cache.
