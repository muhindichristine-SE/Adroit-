How It Works

Projects & Document Control

Create a project for each site. Fill in Client, Contractor, Engineer, Drawn By, Checked By and Reviewed By — all print on the PDF cover page.

Status Quick-Tap

Tap the coloured status badge (Open / In Progress / Closed) on any issue card to cycle through statuses instantly.

Reorder Issues

Use the ⇧ ⇩ buttons on each card to move issues up or down. Tap Float Critical to auto-move all Critical issues to the top.

Bulk Actions

Tap Select to enter bulk mode. Tap cards to choose them, then mark as closed, in-progress, or delete multiple at once.

Export PDF & Word

Full inspection report with cover page, document control, issue list and photos. Works fully offline.

Backup & Restore

Data lives only on this device. Use Backup regularly. Tap RESTORE to reload after clearing browser cache.
